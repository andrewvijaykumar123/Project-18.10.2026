# Wine Quality Prediction

This project applies a Decision Tree classifier to the UCI Wine dataset for multi-class wine quality classification.

## Files

- `wine_quality_prediction.py` — trains and evaluates a Decision Tree model.
- `wine_quality_comparison.py` — compares Decision Tree and Random Forest performance.

## Run

```bash
python wine_quality_prediction.py
python wine_quality_comparison.py
```

## Result

The Decision Tree achieved about 94.44% accuracy on the test set, while the Random Forest achieved 100% accuracy for this split.
